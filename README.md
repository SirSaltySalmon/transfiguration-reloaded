# Ending note
ps. The code works and attempts to use best practices in all where necessary but often is only applicable to the scope of a small game and deliberately simplified or unintuitive to suit development time. Don't take this game's source code too seriously if you're learning to make games!

I originally made this game in 2024, when I first learned to code, until my laptop got bluescreened and I lost all my work. That experience taught me to use GitHub. Though harrowing, it also gave me the opportunity to make the game the best version it could be, helping me brush up the vision from 2d to 3d, and implement WAY better coding practices. Hence, the -reloaded part in the repo. I'm glad to see this project finally coming to life and I hope it can inspire more people to make games, and push through tough times!
